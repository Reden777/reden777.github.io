After loading a file to MultiHasher, its hash code will appear. You can MultiHash it again with 888 Levels, 888888 Repeats in PC/CLI, or 888 Levels, 88888 Repeats in Android.
The resulting code should be as, or even more powerful than the ones I have here.

My process was different. I did "sha512sum name_of_file" (a Linux command to produce the SHA2-512, which is not the better SHA3 but still functional and omnipresent across Linux distros), then I copied the resulting b942... name_of_file.extension into MultiHasher, and hashed it again.
